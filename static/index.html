What it does

Everything you need for offline deployments

.deb & .rpm Bundles
Download packages and all their transitive dependencies for Debian and RPM-based distributions in one click.

True Air-Gap Support
Built for restricted networks. Generate a single .tar.gz you can copy onto any USB drive or secure share.

Docker-Isolated Builds
Each build runs inside a clean container matching the target distro — no host pollution, reproducible every time.

Extra Repos & Presets
Enable third-party repos (Docker CE, Kubernetes, Grafana…) before bundling, or pick a common scenario preset to populate packages instantly.

Multi-Arch
Target amd64 or arm64 from the same UI — ideal for mixed server fleets and modern ARM workloads.
📋
Live Build Log
Watch real-time terminal output as packages are resolved, downloaded, and archived. Full job history with one-click re-download.
